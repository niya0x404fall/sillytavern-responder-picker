# Выбор отвечающего для SillyTavern

Небольшое расширение для группового чата SillyTavern. Открывает список участников по стрелке над полем ввода или долгим нажатием кнопки отправки. В настройках расширения можно скрыть стрелку и выбрать вид списка: короткие строки или кружки.

Кнопка ▶ отправляет написанный черновик как сообщение пользователя, затем запускает ответ выбранного персонажа. Если поле ввода пустое, запускает ответ на последнее сообщение. Кнопка с глазом включает или отключает участника группы. Обычная отправка работает по настройкам группы SillyTavern.

## Установка

В SillyTavern откройте «Расширения» → «Установить расширение» и вставьте ссылку на этот GitHub-репозиторий. После установки обновите страницу.

Для ручной установки поместите `index.js`, `style.css` и `manifest.json` в `data/default-user/extensions/QuickReplyPicker/`, затем перезапустите SillyTavern и обновите страницу.

Версия: 0.3.12.
