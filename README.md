# Выбор отвечающего — Beta 0.3.13-beta.1

Экспериментальная отдельная сборка для проверки совместимости с White Dome, Starlight и другими темами SillyTavern.

## Что изменено
- Выпадающий список теперь открывается отдельным верхним слоем (`document.body`), не внутри панели ввода.
- При открытии и изменении размеров экрана его положение рассчитывается относительно кнопки или поля ввода.
- Укреплены стили круглых аватаров, кнопок и фона против глобального `* { ... !important; }` из тем.
- Логика `/trigger`, `/member-enable`, `/member-disable` и долгого нажатия оставлена без изменений.
- Настройки беты отделены от стабильной версии.

## Установка для теста
Скопируйте папку `QuickReplyPickerBeta` в `SillyTavern/data/default-user/extensions/`, перезапустите SillyTavern и обновите страницу.

**ВАЖНО:** не включайте одновременно исходный QuickReplyPicker и QuickReplyPickerBeta: у них одинаковые ID элементов интерфейса и обработчики кнопки отправки. На время тестирования отключите стабильное расширение, не удаляя его. После теста можно отключить Beta и вернуться к стабильной версии.

## Что проверить
1. White Dome: кнопка видна, список открывается, не пропадает за вводом или быстрыми ответами.
2. White Dome: работоспособны ▶, значок глаза, удержание кнопки отправки.
3. Starlight: внешний вид и всё поведение остались прежними (кроме наложения слоёв меню).
4. Поворот экрана, открытие клавиатуры, длинные имена и список с прокруткой.

Бета не правит и не перекрашивает Quick Replies: читаемость их кнопок на White Dome задаёт сама тема.
