# Выбор отвечающего для SillyTavern

Расширение для групповых чатов SillyTavern: позволяет выбрать, кто из участников ответит следующим. Откройте список по стрелке над полем ввода или долгим нажатием кнопки отправки. В настройках можно скрыть стрелку и переключить вид списка: строки или кружки.

Кнопка ▶ отправляет написанный черновик как сообщение пользователя, затем запускает ответ выбранного персонажа. Если поле ввода пустое, запускает ответ на последнее сообщение. Кнопка с глазом включает или отключает участника группы. Обычная отправка работает по настройкам группы SillyTavern.

## Установка и обновление

В SillyTavern откройте «Расширения» → «Установить расширение» и вставьте адрес репозитория GitHub. Для обновления ранее установленной стабильной версии используйте кнопку обновления в менеджере расширений.

Для ручной установки разместите `index.js`, `style.css`, `manifest.json` и `README.md` в `data/default-user/extensions/QuickReplyPicker/` и обновите страницу.

## Что нового в 0.3.13

- Выпадающий список открывается в отдельном верхнем слое, чтобы темы не обрезали его.
- Положение списка пересчитывается при изменении размеров экрана, прокрутке и открытии мобильной клавиатуры.
- Стрелка с участниками поднимается над панелью Quick Replies при обнаружении пересечения, в том числе когда быстрые команды занимают несколько строк.
- Усилена защита оформления кнопки и списка от глобальных CSS-правил тем (например, White Dome).
- Сохранена логика выбора отвечающего, отключения участников и долгого нажатия, а также прежние ключи пользовательских настроек версии 0.3.12.

### Известное ограничение

На некоторых мобильных темах плавающая кнопка может перекрывать счётчик токенов. Это не влияет на генерацию, но расположение будет доработано отдельно.

Версия: 0.3.13.
